1.1 - Représentation des données

Les différents types de données

Variable quantitative (continue et discrète)

Une variable quantitative représente une quantité que l'on peut mesurer ou compter. Elle est exprimée avec des nombres et permet de faire des calculs, comme une moyenne.

  • Variable discrète : Elle prend des valeurs précises, généralement des nombres entiers. Elle provient du comptage et ne peut pas prendre toutes les valeurs entre deux nombres.
    Exemples : Le nombre d'élèves dans une classe, le nombre de pièces dans une maison ou le nombre de points obtenus dans un jeu.
  • Variable continue : Elle peut prendre n'importe quelle valeur dans un intervalle. Elle provient généralement d'une mesure.
    Exemples : La taille d'une personne (1,75 m), le temps pour courir 100 mètres ou la température extérieure.

Variable qualitative (nominale et ordinale)

Une variable qualitative décrit une caractéristique ou une catégorie. Elle utilise des mots ou des catégories plutôt que des nombres pour classer les données.

  • Variable nominale : Les catégories n'ont pas d'ordre particulier.
    Exemples : La couleur des yeux (bleu, vert, brun), la marque d'un téléphone ou le groupe sanguin (A, B, AB, O).
  • Variable ordinale : Les catégories ont un ordre ou un classement logique, mais la différence entre les catégories ne peut pas être mesurée précisément.
    Exemples : Le niveau de satisfaction (très satisfait, satisfait, insatisfait), une mention obtenue à un examen ou le niveau d'études (secondaire, collégial, universitaire).

Certains types de diagrammes

Diagramme à bandes

Explication : Ce diagramme utilise des bandes séparées par des espaces. La hauteur ou la longueur d'une bande représente la fréquence ou le pourcentage d'une catégorie.
Contexte d'utilisation : Il est surtout utilisé pour comparer des données qualitatives (nominales ou ordinales) ou des données quantitatives discrètes avec peu de valeurs différentes.

Histogramme

Explication : L'histogramme ressemble à un diagramme à bandes, mais les bandes se touchent. L'axe horizontal est divisé en intervalles de valeurs numériques.
Contexte d'utilisation : Il est utilisé pour représenter la distribution de données quantitatives continues. Les bandes qui se touchent montrent que les données sont continues.

Diagramme circulaire

Explication : Aussi appelé « camembert », ce diagramme divise un cercle en plusieurs sections. Chaque section représente une partie du total (100 %).
Contexte d'utilisation : Il est utilisé pour montrer comment un total est réparti entre différentes catégories. Il fonctionne mieux lorsqu'il y a peu de catégories, idéalement moins de 6.

Diagramme à ligne brisée

Explication : Ce graphique relie plusieurs points avec des lignes pour montrer comment une valeur change. L'axe horizontal représente souvent le temps.
Contexte d'utilisation : Il est principalement utilisé pour montrer l'évolution d'une variable quantitative au fil du temps, comme la température pendant plusieurs mois ou le prix d'une action.
